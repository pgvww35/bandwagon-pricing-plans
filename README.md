## 线路差异：为什么同样是 1 核 1GB，价格差 3 倍多

搬瓦工的套餐配置经常看起来差不多，但价格差很多，差价几乎全部在线路上。官网上对线路的分级大致是这样的：

- **普通线路（DC2/DC4/DC8 等常规机房）**：走普通国际线路或 CN2 GT，晚高峰时段到大陆的速度会打折扣，适合建站给海外用户看、跑测试、挂学习用的服务这类对延迟不敏感的场景。

- **香港 CN2 GIA**：机房就在香港，到大陆延迟通常在几十毫秒级别，三网直连，是搬瓦工线路的天花板，价格也最高。

同一个物理配置（比如 2 核 2GB 内存 40GB SSD），放进普通机房和放进香港机房，年付价格能差出 800 美元。所以选套餐之前先想清楚：你的使用场景对"晚高峰速度"有多敏感。
